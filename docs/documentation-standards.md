# Documentation Standards

## Authority
- README.md is the project entry point.
- Architecture and design belong under docs/.
- Avoid duplicating normative requirements.

## Documentation Requirements
- Distinguish facts from recommendations.
- Describe authoritative inputs and outputs.
- Document GraphQL rate-limiting behavior.
- Prefer concise, testable statements.

## Examples
- Commands must be copyable.
- Use repository-relative paths.
- Avoid placeholder success claims.
